# Options Strategy Workbench

本地运行的股指期权组合研究工具。所有组合、定价、风险和情景计算都在浏览器中完成；不连接行情服务、云端 API 或交易系统。

## 启动

```sh
npm install
npm run dev
```

生产构建与检查：

```sh
npm run build
npm run test
```

## 使用

1. 在顶部设置标的、指数点位、到期日、合约乘数与定价模型。
2. 使用 `ADD CALL` 或 `ADD PUT` 添加单腿。每条腿独立设置方向、执行价、成交权利金、张数、乘数、到期日和 IV。
3. 需要手动 Greeks 时打开 `EDIT LEG GREEKS`，填写**单份期权报价**的希腊值。未填值在组合汇总中显示 `N/A`。
4. 组合变化会即时更新损益图、规则识别、风险注释和情景估值。
5. 可在左侧命名保存组合，或用顶栏 JSON 图标导入/导出；当前组合和命名组合保存在浏览器 LocalStorage。

工作台不会提供策略模板、策略选择器或推荐功能。识别结果仅描述用户已经搭建的组合。

## 口径

- 货币金额以人民币元显示；期权报价和执行价以指数点口径输入，张数与乘数用于换算实际金额。
- 到期腿损益为 `方向 × (到期内在价值 − 成交权利金) × 张数 × 合约乘数`。
- 图表损益精确地在执行价处分段。最大值、无界尾部和盈亏平衡点由分段斜率及端点求解，不从图表采样值估计。
- 到期净损益扣除开仓费和到期结算费；不扣除平仓费。费用按元/张输入。净权利金单列显示，不包含费用。
- 手动 Delta、Gamma、Theta、Vega、Rho 使用单份期权报价口径。Vega/Rho 输入每 1.00 波动率/利率变动的理论价格敏感度，输出按每 1 个百分点转换；再乘方向、数量和合约乘数。缺失项目为 `N/A`，不当作零。
- BSM 使用现货、无风险利率、股息率；Black–76 使用远期价格。Black–76 的 Delta 以远期/现货比率映射回现货点位，未把远期 Delta 与现货 Delta 直接相加。
- 模型 Greeks 的 Vega/Rho 以每 1 个 IV/利率百分点显示；Theta 以每天显示。Greeks 表示局部价格敏感度。
- 情景估值将 IV 平行移动指定百分点，同时保留各腿初始 IV 差异。浮动期权用所选模型估值；已经到期的腿按内在价值现金结算。初始价值使用实际成交权利金，而非模型理论价格。
- 含多个到期日的组合标记 `MULTI-EXPIRY STRUCTURE`。单一到期统计不适用时显示 `N/A`；情景分析使用统一估值日逐腿定价。简化情景不模拟路径依赖、提前调整或实际结算价形成过程。
- 国内股指期权按欧式行权、现金交割提示；实际到期结算价可能不同于收盘价。卖出期权时显示 `MARGIN NOT CALCULATED`。

## 策略规则

基于期权类型、Long/Short、执行价、数量和到期日进行本地规则匹配。相同合约的反向数量会在识别输入中净额化，但原始腿仍保留在界面。当前包括单腿、多空看涨/看跌价差、跨式、宽跨式、蝶式、铁蝶、铁鹰、比例价差及跨期/对角组合；其他结构显示 `CUSTOM STRATEGY`。策略变化才触发提示，改权利金、IV 或 Greeks 不触发重复通知。

## 已知边界

- 当前估值日固定为 2026-10-12；修改代码中的 `TODAY` 常量可设为其他估值日期。
- 手动 Greeks 需要用户提供一致单位的数据；模型 Greeks 依赖输入参数与所选定价假设。
- 图表表示到期内在价值曲线，不表示期限内可成交价格或保证金占用。
- LocalStorage 数据只保存在当前浏览器配置中，清理浏览器存储会移除本地命名组合。
