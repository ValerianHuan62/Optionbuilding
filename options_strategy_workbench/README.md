# Optionbuilding · Options Strategy Workbench

play options like building blocks！

本地运行的股指期权组合研究工具。所有组合、定价、风险和情景计算都在浏览器中完成；不连接行情服务、云端 API 或交易系统。

## 启动

```sh
npm install
npm run dev
```

生产构建与检查：

```sh
npm run build
npm run test
```

## 使用

1. 在顶部设置标的、指数点位、估值日、到期日和合约乘数；定价统一使用 BSM。
2. 从左侧导入期权链或添加执行价，录入各腿权利金与 IV，再用 `+L` / `−S` 搭建组合。
3. 右侧 Portfolio Greeks 按建仓估值点的 BSM 参数计算；情景滑块不改它。情景区的 Scenario Greeks 随滑块独立重算。
4. 组合变化会即时更新损益图、规则识别、风险注释和情景估值。
5. 可在左侧命名保存组合，或用顶栏 JSON 图标导入/导出；当前组合和命名组合保存在浏览器 LocalStorage。

工作台不会提供策略模板、策略选择器或推荐功能。识别结果仅描述用户已经搭建的组合。

## 口径

- 货币金额以人民币元显示；期权报价和执行价以指数点口径输入，张数与乘数用于换算实际金额。
- 到期腿损益为 `方向 × (到期内在价值 − 成交权利金) × 张数 × 合约乘数`。
- 图表损益精确地在执行价处分段。最大值、无界尾部和盈亏平衡点由分段斜率及端点求解，不从图表采样值估计。
- 到期与情景 PnL 均为不扣费用的毛损益；费用输入不改变图表或最大盈利、最大亏损。净权利金单列显示，不包含费用。
- 期权链可保留导入的行情 Greeks 供参考；组合与情景 Greeks 统一由 BSM 按现货、无风险利率、股息率、逐腿 IV 和剩余期限计算。汇总时只乘方向和数量，不乘合约乘数；PnL 的人民币换算单独乘合约乘数。
- 上证50/HO、沪深300/IO、中证1000/MO 的年化股息率分别固定为 2.8%、2.3%、1.1%；旧本地状态和已保存策略中的这些指数股息率会按此规则覆盖。自定义指数仍可手动输入。
- BSM Greeks 的 Vega/Rho 以每 1 个 IV/利率百分点显示；Theta 以每天显示。Portfolio Greeks 使用未冲击的建仓输入，Scenario Greeks 使用情景输入。
- 情景估值日可在顶部选择；剩余自然日为「到期日 − 估值日 − 时间推进天数」，一年按 365 天。IV 平行移动指定百分点，同时保留各腿初始 IV 差异。存续期权用 BSM 逐腿估值；已经到期的腿按现货内在价值现金结算。初始价值使用实际成交权利金，而非模型理论价格。
- 同到期组合若因逐档 IV 或模型输入不一致而超出贴现后的到期结构损益界限，情景显示 `N/A`，不会截断为最大盈利或最大亏损。此时应核对每腿 IV、估值日、利率与标的价格。
- 含多个到期日的组合标记 `MULTI-EXPIRY STRUCTURE`。单一到期统计不适用时显示 `N/A`；情景分析使用统一估值日逐腿定价。简化情景不模拟路径依赖、提前调整或实际结算价形成过程。
- 国内股指期权按欧式行权、现金交割提示；实际到期结算价可能不同于收盘价。卖出期权时显示 `MARGIN NOT CALCULATED`。

## 策略规则

基于期权类型、Long/Short、执行价、数量和到期日进行本地规则匹配。相同合约的反向数量会在识别输入中净额化，但原始腿仍保留在界面。当前包括单腿、多空看涨/看跌价差、跨式、宽跨式、蝶式、铁蝶、铁鹰、比例价差及跨期/对角组合；其他结构显示 `CUSTOM STRATEGY`。策略变化才触发提示，改权利金、IV 或 Greeks 不触发重复通知。

## 已知边界

- 默认估值日为上海时区的当天，可在顶部修改以复算历史情景；输入的现货、IV 和利率应与所选估值日对应。旧版已保存组合若未记录估值日，加载时沿用当前估值日并在策略卡片提示。
- 旧版远期模型的保存快照迁移到 BSM 时，会暂用旧远期作为现货并显示原始值提示；使用前应核对现货。重新保存后采用当前 BSM 设置。
- 图表表示到期内在价值曲线，不表示期限内可成交价格或保证金占用。
- LocalStorage 数据只保存在当前浏览器配置中，清理浏览器存储会移除本地命名组合。
